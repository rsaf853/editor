## r♡sieditor

문장을 이미지 카드로 만드는 에디터의 간소화 버전입니다. `index.html` 파일 하나로 동작합니다.

### 입력 규칙 (붙여넣기만 하면 자동 인식)
| 입력 | 결과 |
|---|---|
| `이름｜대사` · `이름: 대사` | 대사 정렬 (따옴표 없어도 대사색) |
| `<sub>글자</sub>` | 작은 보조 글씨 (대사 밑에 붙음) |
| `*별표*` | 보조색 (별표 기호는 숨김) |
| `"대사"` | 대사색 |
| `**굵게**` `__밑줄__` `~~취소선~~` `==형광펜==` | 인라인 서식 |
| `!!강조!!` | 강조색 글자 |
| `> 문장` | 인용 바 |
| `## 소제목` | 굵은 대사색 줄 (`#` 숨김) |
| `- 항목` · `* 항목` · `• 항목` | 목록 (둘째 줄부터 들여 맞춤) |
| `---` / `===` | 구분선 / 페이지 나눔 |

설정과 글은 브라우저에 자동 저장됩니다. 이미지는 저장되지 않습니다.
